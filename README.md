# 温习

225 道习思想练习题，原生 HTML、CSS、JavaScript。无需安装、无需构建。

## 文件

- `index.html`：语义化页面、导航、设置对话框。
- `style.css`：响应式样式；桌面侧栏、手机顶部导航。
- `app.js`：页面状态、练习、判分、间隔安排、笔记与备份。
- `data.js`：独立题库，稳定 ID（例如 `multi-17`）。

可直接打开 `index.html`，也可用任意静态服务器托管本目录。

## 数据约定

题目字段：`id`、`type`、`num`、`stem`、`options`、`answer`、`points`、`explanation`、`topic`、`flag`、`sources`。

`answer` 使用选项字母，判断题使用 `T` / `F`。多选必须完全匹配。非空 `flag` 表示存在疑问：不自动判分，也不进入随机自测。主观题通过 `points` 供学习者核对与自评。

题干来源于学生版，无教师标准答案。参考答案为辅助整理；待核对题有单独标记，不能作为官方评分依据。

学习记录使用 localStorage 键 `wenxi-study-v1`；含版本号、逐题记录、历史、设置与未完成练习。导入时校验数据并明确确认替换。记录只在当前浏览器保留；不同域名与离线文件不会自动同步，使用 JSON 备份迁移。

## 复习规则

优先到期题，再按主题交错加入未练题。没记住：10 分钟；模糊：1 天；记住：按阶段 1、3、7、14、30 天。题目一旦答错进入错题，标记记住后移出；复习到期时间仍保留。

## 可访问性与自动化

使用原生按钮、文本框、选择框与 dialog；控件有可访问名称，选项用 `aria-pressed` 表示选择。所有动作使用稳定的 `data-action`，所有题目使用稳定 ID；无需依赖视觉坐标。样式和题库独立于交互逻辑。

浏览器验收已覆盖：多选完整匹配、主观题不自动判分、存疑题排除、错题、收藏、筛选、笔记与回答保存、间隔安排、刷新续做、备份导入导出、20 题自测、手机页面溢出检查。

学习方法参考：https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html
研究支持检索练习与分散练习；本项目采用的具体间隔是实用规则，不是研究证明的最优排程。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 / (root)，保存后即可发布。以后修改 main 分支中的文件会自动更新网页，无需构建命令或第三方依赖。

GitHub Pages 与原站点的学习进度不会自动同步。在原站点的设置中导出备份，再在新站点导入。

GitHub 版本使用设备自带的中文字体，没有额外字体下载。
